คู่มือระบบห้องความดันบวกกันฝุ่น PM2.5

ระบบใช้บอร์ด 3 ตัวทำงานร่วมกัน: ESP32U วัดอากาศนอกห้อง ส่งให้ ESP32 MASTER ผ่าน ESP-NOW, UNO R4 WiFi วัดอากาศในห้อง ส่งให้ MASTER ผ่าน UDP, แล้ว MASTER คำนวณสั่ง Relay เปิด/ปิดพัดลม + ส่งข้อมูลขึ้น Google Sheet

สถาปัตยกรรมระบบ

บทบาทของแต่ละบอร์ด

บอร์ดตำแหน่งเซ็นเซอร์ส่งข้อมูลทางหน้าที่
ESP32Uนอกห้องGP2Y1014 + BMP180ESP-NOWวัดฝุ่น PM2.5 + ความดันอากาศ นอกห้อง ส่งถึง MASTER โดยตรง
UNO R4 WiFiในห้องGP2Y1014 + BMP180UDP Broadcast (WiFi)วัดฝุ่น PM2.5 + ความดันอากาศ ในห้อง ส่งผ่าน WiFi บ้าน
ESP32ตัวกลางไม่มีWiFi (Internet)รับข้อมูลจากทั้งสองตัว คำนวณ คุม Relay พัดลม ส่ง Google Sheet

ตรรกะควบคุมพัดลม

สถานะเงื่อนไขพัดลม
ปกติเริ่มต้น / ข้อมูลยังไม่ครบเปิด (สร้างความดันบวก)
ตัดพัดลมฝุ่นในห้อง < นอกห้อง และ ความดันในห้องสูงเกิน 0.30 hPaปิด (คนอึดอัด)
เปิดกลับฝุ่นในห้อง ≥ นอกห้อง หรือ ความดันตกต่ำกว่า 0.15 hPaเปิดกลับ
Fail-safeเซ็นเซอร์ตัวใดเงียบ > 30 วินาทีเปิด (ปลอดภัยเรื่องฝุ่น)
ทำไม UNO R4 ใช้ ESP-NOW ไม่ได้: UNO R4 WiFi มีชิป ESP32-S3 อยู่ในบอร์ด แต่ทำหน้าที่เป็นแค่ WiFi bridge ผ่าน firmware ของ Arduino (WiFiS3 library) ไม่เปิด API ของ ESP-NOW ให้ใช้ได้ จึงใช้ UDP Broadcast ผ่าน WiFi บ้านแทน ซึ่งก็เป็นการสื่อสารตรงถึง MASTER ไม่ต้องมีเซิร์ฟเวอร์กลาง

แผนภาพการต่อสาย: ESP32U (โหนดนอกห้อง)

ตารางการต่อสาย ESP32U

สีสายจาก ESP32Uไปยัง GP2Y1014หมายเหตุ
แดง5V (VIN)GP2Y ขา 6 (VCC)ไฟเลี้ยงเซ็นเซอร์
แดง5V ผ่าน R 150ΩGP2Y ขา 1 (V-LED)+ C 220µF ระหว่างขา 1 กับ GND
ดำGNDGP2Y ขา 2 (LED-GND) + ขา 4 (S-GND)ต่อ GND ทั้งสองขา
เหลืองGPIO 25GP2Y ขา 3 (LED)สัญญาณพัลส์ LED
ชมพูGPIO 34GP2Y ขา 5 (Vo)สัญญาณ Analog ฝุ่น
ส้ม3V3BMP180 VCCไฟเลี้ยง 3.3V
ดำGNDBMP180 GND
ฟ้าGPIO 21 (SDA)BMP180 SDAI2C Data
เขียวGPIO 22 (SCL)BMP180 SCLI2C Clock
เทาGPIO 33ปุ่มกด → GNDกดค้าง = สแกน channel ใหม่

แผนภาพการต่อสาย: UNO R4 WiFi (โหนดในห้อง)

ตารางการต่อสาย UNO R4 WiFi

สีสายจาก UNO R4ไปยัง GP2Y1014หมายเหตุ
แดง5VGP2Y ขา 6 (VCC)
แดง5V ผ่าน R 150ΩGP2Y ขา 1 (V-LED)+ C 220µF ลง GND
ดำGNDGP2Y ขา 2 + ขา 4
เหลืองD7GP2Y ขา 3 (LED)สัญญาณพัลส์ LED
ชมพูA0GP2Y ขา 5 (Vo)ADC อ่านค่าฝุ่น
แดง5VBMP180 VCCR4 ใช้ 5V (GY-68 มี regulator)
ดำGNDBMP180 GND
ฟ้าSDABMP180 SDA
เขียวSCLBMP180 SCL
ความแตกต่างจาก ESP32U: UNO R4 WiFi เป็นลอจิก 5V ดังนั้น ADC ของ A0 อ่านได้ถึง 5V (ต่างจาก ESP32 ที่ 3.3V) และ BMP180 (GY-68) ต่อ VCC = 5V ได้เพราะโมดูลมี regulator ในตัว ขา I2C SDA/SCL ของบอร์ดอยู่ที่ตำแหน่ง SDA/SCL ของ header (ไม่ใช่ A4/A5)

แผนภาพการต่อสาย: ESP32 MASTER (ตัวกลาง)

ตารางการต่อสาย ESP32 MASTER

สีสายจาก ESP32ไปยังหมายเหตุ
แดง5VRelay VCCไฟเลี้ยงโมดูล Relay
ดำGNDRelay GND
ม่วงGPIO 26Relay INสัญญาณสั่งเปิด/ปิด Relay
เทาGPIO 33ปุ่มกด → GNDกดค้าง = Reconnect WiFi
น้ำตาลRelay COMขั้วบวก Adapter питанияไฟเลี้ยงพัดลมวิ่งผ่าน COM-NO
น้ำตาลRelay NOขั้วบวก พัดลมต่อเมื่อ Relay ON
น้ำตาลขั้วลบ Adapterขั้วลบ พัดลมต่อตรง (GND ร่วม)
สำคัญเรื่อง Relay:
• ถ้า Relay ไม่ทำงานสลับกัน ให้แก้ RELAY_ACTIVE_HIGH = false ในโค้ด (โมดูล Relay หลายรุ่นเป็น Active LOW)
• โมดูล Relay แบบ Optocoupler: ต่อ VCC → 5V, JD-VCC → 5V แยกจากถ้ามี jumper ถอดได้
• ⚠ ⚠ พัดลม AC 220V อันตราย! ให้ช่างไฟฟ้าต่อวงจรด้าน OUTPUT ของ Relay

ขั้นตอนติดตั้งและใช้งาน

1. ติดตั้ง Library ที่ต้องใช้

บอร์ดLibraryวิธีติดตั้ง
ESP32U + ESP32Adafruit BMP085 LibraryArduino IDE → Tools → Manage Libraries → ค้นหา "Adafruit BMP085" → ติดตั้ง (รวม Adafruit BusIO ด้วย)
UNO R4 WiFiAdafruit BMP085 Libraryเหมือนด้านบน + ต้องเลือก Board: "Arduino UNO R4 WiFi" ใน Arduino IDE
ทั้งหมดESP32 Arduino Core Boards Manager → "esp32" by Espressif (เวอร์ชัน 2.x หรือ 3.x)

2. Deploy Google Apps Script

  1. เปิด Google Sheet ที่ต้องการ → Extensions → Apps Script
  2. ลบโค้ดเดิมออก แล้ววางโค้ดจากไฟล์ code.gs ที่ให้มา
  3. กด Deploy → New deployment
    • Execute as: Me
    • Who has access: Anyone
  4. คัดลอก URL ที่ได้ ไปใส่ใน GOOGLE_SCRIPT_URL ในไฟล์ esp32_master.ino

3. อัปโหลดโค้ด (ทำตามลำดับ)

  1. อัปโหลด ESP32 Master ก่อน
    ใส่ชื่อ WiFi + PASSWORD + GOOGLE_SCRIPT_URL → เลือก Board "ESP32 Dev Module" → Upload
    เปิด Serial Monitor (115200) → จด MAC Address ที่พิมพ์ออกมา เช่น 24:6F:28:AA:BB:CC
  2. ใส่ MAC ใน esp32u_node.ino
    เอา MAC ที่ได้มาใส่ใน MASTER_MAC[] → เลือก Board → Upload
  3. ใส่ WiFi ใน unor4_node.ino
    ใส่ ssid + password → เลือก Board "Arduino UNO R4 WiFi" → Upload
สลับบทบาทได้: ถ้าอยากให้ ESP32U อยู่ในห้อง UNO R4 อยู่นอกห้อง แค่เปลี่ยน NODE_ID เป็น "INSIDE" หรือ "OUTSIDE" ในไฟล์ node ทั้งสอง MASTER จะจำแนกจากชื่อ node อัตโนมัติ

4. คาริเบรต (ทำหลังอัปโหลดเสร็จ)

รายการวิธีทำใส่ค่าตรงไหน
Baseline ฝุ่นปิดพัดลม ปล่อยให้อากาศนิ่ง → ดูค่า Voltage/Vo ใน Serial Monitor → ปรับ baseline ใน readDustDensity()ไฟล์ .ino ของแต่ละตัว
Pressure Offsetเปิดประตูทุกบาน + ปิดพัดลม → ความดันใน=นอก → ดู dP ของ MASTER → เอาค่านั้นใส่เป็น offsetPRESSURE_OFFSET_HPA ใน esp32_master.ino
Relay Activeสั่ง Relay ดูว่า ON/OFF ถูกต้องไหม → ถ้าสลับกัน แก้ค่าRELAY_ACTIVE_HIGH = false

5. ปรับเกณฑ์ควบคุม

ตัวแปรค่าเริ่มต้นอธิบาย
DP_OFF_HPA0.30dP (hPa) ที่ปิดพัดลม (0.30 = 30 Pa)
DP_ON_HPA0.15dP ที่เปิดพัดลมกลับ (Hysteresis)
DUST_MARGIN_UG3.0ฝุ่นในต้องน้อยกว่านอกเกินค่านี้ (ug/m3)
NODE_TIMEOUT_MS30000เซ็นเซอร์เงียบเกินนี้ = Fail-safe (ms)
MIN_TOGGLE_MS30000สลับ Relay ถี่สุดทุกกี่ ms (กัน Relay พัง)
EMA_ALPHA0.4ความลื่นของกรอง (0.1=ลื่นมาก, 0.9=ตอบสนองเร็ว)

6. แก้ปัญหา

อาการสาเหตุที่เป็นไปได้วิธีแก้

dP แกว่งมากNoise ของ BMP180 (ปกติ)ลด EMA_ALPHA เช่น 0.2 / คาริเบรต offset ใหม่

ข้อควรระวัง

• ⚠ ไฟฟ้า 220V อันตราย! ด้าน OUTPUT ของ Relay ที่ต่อกับพัดลม AC ต้องให้ช่างไฟฟ้าทำ
• GP2Y1014 ต้องใช้ไฟ 5V (ต่อจาก VIN/5V ของบอร์ด) ห้ามใช้ 3.3V
• แนะนำให้ fix Router 2.4GHz ไว้ที่ Channel 1, 6 หรือ 11 (ไม่ใช่ Auto)
• BMP180 มีความแม่นยำ ±1 hPa (±100 Pa) ในการวัดแบบ absolute แต่ differential accuracy ดีกว่า ~±12 Pa ด้วย EMA + Hysteresis จึงพอใช้งานสำหรับ的趋势监控
• ถ้าต้องการความแม่นเรื่องความดันต่าง >5 Pa แนะนำเซ็นเซอร์เฉพาะทาง เช่น SDP810-Differential
